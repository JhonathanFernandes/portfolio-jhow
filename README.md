# JHOW.DEV — Portfólio

Portfólio pessoal de **Jhonathan Fernandes**, desenvolvido para apresentar minha trajetória de aprendizado, projetos e tecnologias com as quais venho trabalhando.

**Acesse o site:** https://portfolio-jhow.vercel.app

## Sobre o projeto

Este site reúne informações sobre minha trajetória no desenvolvimento de software, meus projetos e as tecnologias que venho estudando e aplicando na prática.

A identidade visual combina uma interface escura, detalhes em verde, tipografia técnica e interações para criar uma apresentação alinhada à minha área de atuação.

## Tecnologias utilizadas

- **HTML5** — estrutura e conteúdo.
- **CSS3** — layout, identidade visual e responsividade.
- **JavaScript** — interações e comportamentos da interface.
- **Git e GitHub** — versionamento do código.
- **Vercel** — hospedagem do portfólio.
